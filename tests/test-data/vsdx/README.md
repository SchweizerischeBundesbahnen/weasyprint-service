# VSDX test data

`apache-poi-test.vsdx` is `test-data/diagram/test.vsdx` of [Apache POI](https://github.com/apache/poi/blob/trunk/test-data/diagram/test.vsdx), licensed under the Apache License 2.0, the license of this repository. The file is unchanged (git blob `1fa690356e477ef15c1e9605e9f7312576b382f7`).

It is a container shape with a blue header bar `#41719c`, two lines of text and a star. `tests/test_container_vsdx.py` checks for the header color, which LibreOffice 25.2 and 26.8 both draw.
